🌿 2. Пошаговая инструкция по работе с Git и GitHub

Все работают через персональные ветки! Никто не делает прямой push в ветку main. Все изменения принимаются через Pull Request.

1 Клонирование репозитория на свой компьютер

Откройте терминал (Git Bash / VS Code) и выполните:

git clone https://github.com/cozy-bit/euphoria-fashion.git cd euphoria-fashion

2 Установка зависимостей проекта

npm install

3 Создание своей ветки (Branch)

Создайте ветку под свой пул задач:

# Для Кибриё: git checkout -b feature/auth-and-orders # Для Толибова: git checkout -b feature/static-and-account

4 Запуск локального сервера разработки

npm run dev

Проект откроется в браузере по адресу: http://localhost:5173

5 Сохранение работы (Commit)

git status git add . git commit -m "feat: complete empty cart and 404 pages"

6 Отправка своей ветки в GitHub (Push)

git push -u origin НАЗВАНИЕ_ВАШЕЙ_ВЕТКИ

7 Создание Pull Request (PR)

Перейдите на страницу репозитория в GitHub, нажмите зеленую кнопку "Compare & pull request", напишите краткое описание сделанных страниц и отправьте запрос тимлиду (Амирхону) на проверку и слияние в main.

💡 5. Инструкции и советы разработчикам

📌 Памятка для Амирхона (Тимлид):
• Начни с базового скелета: App.jsx (роутер), Header.jsx, Footer.jsx и контекстов CartContext, WishlistContext.
• Подготовь переиспользуемый ProductCard.jsx — он понадобится и тебе в каталоге, и Кибриё в карточке товара и вишлисте.
• Проверяй Pull Request от команды и сливай их в ветку main.
📌 Инструкция для Кибриё:
• Ты работаешь с React + Tailwind CSS.
• Для блока авторизации сделай единый компонент-обертку AuthLayout.jsx (слева картинка, справа форма), чтобы не дублировать верстку на 6 страницах.
• Твои страницы: src/pages/auth/, ProductDetailPage.jsx, WishlistPage.jsx, MyOrdersPage.jsx, OrderDetailsPage.jsx.
• Используй готовые UI-компоненты: import Button from '../../components/ui/Button', ProductCard.
📌 Инструкция для Толибова:
• Ты работаешь с React + Чистый модульный CSS (без Tailwind).
• Твои страницы самые легкие и изолированные: ErrorPage, EmptyCart, EmptyWishlist, ConfirmedOrder, ContactDetailsPage, AddAddressPage.
• Для каждого компонента создавай свой файл стилей: например, рядом с EmptyCart.jsx создай EmptyCart.module.css.
• В коде JSX подключай стили так: import styles from './EmptyCart.module.css' и пиши <div className={styles.container}>.
• Твои стили полностью изолированы благодаря CSS Modules — ты можешь писать любые свойства в CSS и быть на 100% уверен, что ничего не сломаешь на других страницах!

💡 5. Роҳнамои махсус барои таҳиягарон

📌 Роҳнамо барои Амирхон (Тимлид):
• Аввал сохтори асосиро ба роҳ монед: App.jsx (роутер), Header.jsx, Footer.jsx ва контекстҳои CartContext, WishlistContext.
• Компоненти умумии ProductCard.jsx-ро омода кунед, чунки ҳам шумо дар каталог ва ҳам Кибриё дар саҳифаи маҳсулот ва вишлист онро истифода мебаред.
• Pull Request-ҳои фиристодаи аъзои дастаро санҷида, ба шохаи main ҳамроҳ намоед.
📌 Роҳнамо барои Кибриё:
• Шумо бо React + Tailwind CSS кор мекунед.
• Барои саҳифаҳои бахши Auth қолаби умумии AuthLayout.jsx-ро истифода баред (акс дар тарафи чап ва форма дар рост), то ки коди такрорӣ кам шавад.
• Саҳифаҳои шумо: src/pages/auth/, ProductDetailPage.jsx, WishlistPage.jsx, MyOrdersPage.jsx, OrderDetailsPage.jsx.
• Аз компонентҳои тайёри UI (Button, ProductCard) истифода баред.
📌 Роҳнамо барои Толибов:
• Шумо бо React + Чиста CSS (CSS Modules) кор мекунед (бе истифодаи ҳатмии Tailwind).
• Барои шумо саҳифаҳои аз ҳама сабуктарин ва ҷудогона дода шудаанд: ErrorPage, EmptyCart, EmptyWishlist, ConfirmedOrder, ContactDetailsPage, AddAddressPage.
• Барои ҳар як саҳифа файли хоси худро кушоед: масалан дар паҳлӯи EmptyCart.jsx файли EmptyCart.module.css-ро созед.
• Дар код чунин истифода баред: import styles from './EmptyCart.module.css' ва дар тег нависед: <div className={styles.container}>.
• Стилҳои шумо бо ин роҳ комилан махсус (изолятсия) мешаванд ва ба дигар саҳифаҳои лоиҳа ҳеҷ халал намерасонанд!
